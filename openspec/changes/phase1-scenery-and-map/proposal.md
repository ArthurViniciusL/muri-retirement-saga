## Why

Phase 1 is an empty scene: the select screen leads nowhere. The next milestone is the
scenery and a route a player can walk from end to end — ground, platforms, parallax,
decoration, obstacles and coins — plus the least movement needed to travel it. Muri's
mechanics and art stay out: the player is a debug rectangle, so level work does not wait
for character art.

## What Changes

- Add `PhaseScene`, one shared implementation driven by `PhaseConfig`, and make
  `Phase1Scene` a three-line subclass. Phase 2 and Phase 3 stay stubs.
- Author the Phase 1 map as Tiled JSON generated by `tools/level/phase1.py` from an
  ASCII layout: a `ground` tile layer and the `obstacles` and `coins` object layers.
- Build the phase tileset at runtime by slicing the framed wall artwork into eight
  tiles: ground and platform, each with top, middle, left corner and right corner.
- Add scenery objects: obstacles that hurt and also block (`cactus_red`, `campfire`),
  obstacles that only block (`cactus`, `rock_formation`, `stone_rock`, `wooden_barrel`,
  `woodlog`, `pebble`, `fox_car`) and decoration (`foliage`,
  `fluffy_cloud`) scattered from a fixed per-phase seed.
- Make common coins collectible, with a debug counter.
- Add a debug layer behind a single flag: the player rectangle (green forward, blue
  going back, red crouched) and a top-left overlay with hearts, coins and state.
- Raise `jumpVelocity` to -840 so a 128 px obstacle is cleared with room to spare, and cap scenery
  obstacles at 96 px.
- Port `VirtualControls` from the abandoned `feat/implement-muri-mechanics` branch;
  keyboard becomes the desktop input.
- Delete the stale `phase1-movement-foundation` change after porting its useful specs.

Rules touched: new `art-scenery-asset-exception.md` and `gameplay-scenery-obstacles.md`;
edits to `code-game-config.md`, `code-phase-config.md`, `art-asset-naming.md`,
`architecture-scene-structure.md`, `ui-virtual-controls.md`, `content-level-design.md`.

## Temporary deviations

Recorded here so they read as scope, not as defects: hearts are a debug counter with no
game over (`gameplay-health.md`), and a fall restarts the phase instead of ending the
run. Both end when the health and game over work lands.

## Non-goals

Muri's art and animations, enemies, thieves, ranged combat, the HUD, the puzzle, pause,
game over, Phase 2 and Phase 3 content.
